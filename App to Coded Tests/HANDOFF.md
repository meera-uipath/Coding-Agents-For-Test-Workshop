## 1. Goal

Build a demo of **Coding Agents for Test** in which one coding agent combines several UiPath skills. The agent:

1. explores a live application
2. identifies a few test use cases
3. creates **requirements** and **test cases** in Test Manager
4. writes **coded test cases** with an **Object Repository**
5. publishes and links them back to Test Manager, and optionally runs them

## 5. Key findings from reading the skills

- **The skills are designed to hand off to each other.** `uipath-test` routes Studio/RPA authoring to `uipath-rpa`, and `uipath-rpa` routes test reports to `uipath-test`.
- **Manual steps lead to the Object Repository.** `uipath-rpa` builds its list of capture targets from the manual test steps (one OR element per Click/Enter/Verify step). That's why the TM test cases with steps get created **before** the coded project.
- **UIA minimum version is `UiPath.UIAutomation.Activities` 26.10.2** (per `uipath-rpa/references/uia-starter-guide.md`). Below that, live capture can't happen and the agent falls back to placeholder selectors marked `TODO Indicate`. The agent must ask before installing or upgrading the package.
- **Coded mode needs a stub first.** A coded `[Workflow]` stub must exist on disk before capture, or `ObjectRepository.cs` won't be generated.
- **`uip rpa init` needs an explicit framework.** It must be given `--target-framework` (Windows vs Portable) and `--expression-language`, and both are immutable afterwards. Omitting the framework silently gives you a Windows project.
- **Publish and link pipeline** (`uipath-test/references/publish-and-link-guide.md`): `uip rpa pack` → `uip or packages upload` → `uip or folders list` → `uip tm testcases list-automations` → `uip tm testcases link-automation`. There's no `uip rpa publish`.
- **Selectors are never hand-written.** Capture is always done with `uia-configure-target`.
- **Studio Web** needs a Solution (`uipath-solution`). A bare project won't show up there.
- `uip tm testsets list-testcases` doesn't show whether a test case has an automation linked. Use `uip tm testcases list-automations`, or check the TM UI.
