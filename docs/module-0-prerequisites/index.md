# Prerequisites

Complete this section **before the workshop**. It covers the accounts you need and the AI assistant you'll work with. The **[Installation Guide](01-installation-guide.md)** then walks you through the setup.

## Accounts and access

Before the workshop, confirm that you can:

✅ Sign in to <a href="https://cloud.uipath.com" target="_blank">UiPath Automation Cloud</a> and open the workshop **organization** and **tenant** shared by your trainer

✅ Can access **Test Manager** and **Orchestrator** in that tenant

✅ See a **machine with an App Test Robot runtime** you can add to your folder (we set this up together in step 10)

✅ Have an **App Test Developer** license — you need it to create Test Automation projects

✅ Have **permission to create Data Fabric entities** — you need it for test data in step 8

✅ Connect **UiPath Assistant** to the Cloud account
