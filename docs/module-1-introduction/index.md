# Test Cloud & Test Manager

## What is Test Cloud?

**Test Cloud** is UiPath's cloud platform for application testing. It brings together:

✅ **Test Manager** — plan, run, manage, and analyze testing

✅ **Studio** — build and automate test cases

✅ **Orchestrator** — run test automation at scale

✅ **App Test Robot** — the robot that runs your automated test cases

✅ **Agentic Testing** — AI agents, such as Autopilot for Testers and Delegate, at every step

![Test Cloud Ecosystem](../assets/images/Test%20Cloud%20ecosystem.png)

## What is Test Manager?

**Test Manager** links requirements to test cases, test sets, and results, so you always know what's tested and what's failing.

![Test Manager](../assets/images/Test%20Manager_Full.png)

## Autopilot for Testers

AI agents built into Test Manager and Studio. Today you'll use:

✅ **Evaluation Agent** — checks requirements for clarity, completeness, and testability

✅ **Test Case Generation Agent** — generates test cases from requirements

✅ **Autopilot for Testers in Studio** — turns a manual test case into an automated one, low-code or coded (C#)

![Built-in agent type](../assets/images/Agent%20type%20OOTB.png)

## Delegate for Test

Through the `uip tm` CLI and the `uipath-test` skill, **Delegate** — or a coding agent such as Claude Code, Codex, Cursor, or GitHub Copilot — can:

✅ **Read** test cases, results, and requirement coverage from Test Manager

✅ **Write** results, defects, and test case updates

✅ **Trigger** test sets and monitor them

That's enough theory — let's build.
